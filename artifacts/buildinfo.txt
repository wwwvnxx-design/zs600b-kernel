== 启动链与校验 ==
U-Boot 位置 : eMMC 0x46000（不在 uboot 分区）
U-Boot 环境 : verify=n ，bootcmd=bootrk
结论        : boot.img 无签名，可自由替换内核；uboot/misc 不用动

== 已知缺陷（本次要修的）==
现象 : UVC 采集卡在 USB-A 上黑屏；libusb 与系统 uvcvideo 两条路径都拿不到数据
证据 : /sys/kernel/debug/usb/devices 中 bus3
       Alloc=-37157048/800us (724078%)， #Iso=-676867   —— ISO 带宽记账溢出为负
       0xAA 哨兵法：URB 全 COMPLETED、包长正常、速率随分辨率变化，但缓冲区一个字节未被写
定性 : dwc_otg 的等时(ISO)调度/DMA 路径缺陷，非调用方问题（bulk 设备 RTL-SDR 正常）
修复 : 只能改内核。RK 3.10 源码树里没有 dwc2，只能修 dwc_otg_310

== 配置指纹 ==
zImage 用 LZO 压缩（boot/kernel.bin 里能扫到 lzop 流），与 rockchip_defconfig 的
CONFIG_KERNEL_LZO=y 一致 => 原厂基本用的就是 Rockchip 公版 defconfig。
/proc/config.gz 不存在、kallsyms 里也没有 kernel_config_data => 内核未内嵌配置，
唯一可用的「配置基线」是 arch/arm/configs/rockchip_defconfig + artifacts/ks_stock.txt。
